# Expert Council

Six enduring specialist agents for Dream Teams. The design is `docs/council/EXPERT_COUNCIL.md` in `appl044/agent-office-ring`.

`council/<agent_id>/` is a person. `SAFEGUARDS.md` is read first on every run. `SESSIONS/` holds council-wide questions.

This repository is private. It holds no keys and no real person's health information.
